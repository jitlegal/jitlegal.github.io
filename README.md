# jitlegal.github.io

Public pages for JIT Legal, served at https://jitlegal.github.io.

| Path | Page |
| --- | --- |
| `/` | Home |
| `/leadfeed/` | Lead Feed |
| `/leadfeed/privacy.html` | Lead Feed privacy policy |

Add a product by creating `site/<product>/` with its own `index.html` and `privacy.html`, and list
it on the home page. Pull requests are checked; `main` is published after the checks pass.
